# Nightscout Push

Простое Android-приложение, которое периодически читает последний SGV из Nightscout API и создает обычное Android-уведомление. Такое уведомление можно переслать на Huawei GT6 через настройки уведомлений Huawei Health.

## Как пользоваться

1. Соберите и установите приложение на Android-телефон.
2. Откройте **Nightscout Push** и разрешите уведомления.
3. Укажите URL Nightscout, например `https://your-nightscout.example`.
4. При необходимости укажите API secret или access token.
5. Выберите интервал проверки, пороги и сохраните настройки.
6. В Huawei Health включите пересылку уведомлений для приложения **Nightscout Push**.

> Android WorkManager не гарантирует проверки чаще системного минимума periodic work. Поэтому интервал автоматически ограничен минимумом 15 минут.

## Что отправляется в уведомлении

Уведомление содержит последнее значение глюкозы в `mg/dL`, стрелку тренда Nightscout, статус диапазона и время измерения. Если данные старше 15 минут, уведомление помечается как устаревшее.
